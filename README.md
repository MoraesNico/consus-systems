# Consus

Sistema web de **Controle de Estoque Simples**: cadastro de produtos, entradas e saídas
com bloqueio de saldo negativo e alerta automático de reposição.

Esse repositório deve conter o conteúdo dos códigos, como optei por HTMX não terá API no
momento então terá somente um repositório.

> Em desenvolvimento orientado por especificação (GitHub Spec Kit). Consulte `specs/`.
